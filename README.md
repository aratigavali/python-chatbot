# Python AI Study Buddy

A beginner-friendly Python chatbot that helps students with basic study-related tasks and conversations.

## Features

- Personalized greeting based on time
- Basic chatbot conversation
- Happy and sad emotion responses
- Study tips
- Interactive AI quiz
- AI, Python and Machine Learning explanations
- Simple rule-based response system

## Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- Conditional Statements
- datetime
- time

## Module 5 Improvement

## How to Run

1. Download or clone this repository.
2. Run `AI STUDY BUDDY.PY` using Python.
3. Enter your name.
4. Ask questions or use features such as study tips, quiz, and topic explanations.
